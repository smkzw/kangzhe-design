# ARCO 机制参考与取舍

本页记录用户指定样例中经本地源码及实际浏览器核对的设计机制。它不覆盖 01–11 的规则，也不要求后续每次制作加载 ARCO 全站。参考文件、截图及版本证据保留在私有验证工作区，公共技能不包含内部台账。

## 采用的机制

| 参考机制 | 康哲站点如何使用 | 必须验证的结果 |
|---|---|---|
| demo 的任务载体展开成业务工作区 | 同一主载体内部按材料展示输入、字段、处理步骤、结果与交接；背景轨道只辅助定位 | 展开态可以回答“发生了什么、依据是什么、交给谁”；不能只是大框与一句标题 |
| 分步改变清单、字段和回执 | 在统一业务状态中派生标题、节点、连线、标签、数字；事实无变化时只揭示，不编造变动 | 每个状态和关系有来源；正常速度能读完；标题和内容一致 |
| 工作项全景的部门×阶段关系与筛选 | 宽屏显示多列关系，筛选同时影响相关节点、数量和连接；完整明细随时可读 | 实际内容和关系利用宽度，不只统计全宽外容器；不把宽屏缩为中央窄列 |
| 从聚合项进入工作项、再进入对象详情 | L0 概览→L1 分项流程/对照→L2 输入、规则、动作、结果或证据，按材料选取，层层增加信息 | 07 的宽容器、层级栈、滚动/焦点/状态返回；不得只扩成三句解释 |
| 明细内部也有输入→处理→输出动线 | 子电影说明更细的局部关系；连接端点由实际布局计算，路径可预采样 | 父层暂停、子层可见才运行，关闭清理；resize 后线不脱离对象 |
| 光场、内容、相机与稳定文字分层 | 以 06 的单属性单时钟和保护区实现；品牌 Logo 和阅读区稳定 | 不因物体透视而扭曲数据文字，光斑不扫过统计数据 |

## 必须改造的部分

- ARCO 部分页面通过滚动位置驱动时间轴，demo 开启自动逐站推进，但这些不等于已满足本包自动循环与接缝要求。康哲电影使用独立自动时钟，自然滚动可随时离开，不复制滚轮拦截、自动长距离滚页或进度轨道。
- ARCO 有形状分裂/聚合、SVG 与 DOM 视觉交接。可借鉴其空间组织，不能据此豁免“一形不切”；本包主载体保持同一节点，子信息在其内部展开。
- ARCO 从工作项点击对象会跨页；不能把这个实际行为误称为完整嵌套栈。康哲站点须明确选择独立详情页或栈式下钻，并真正验证来源、滚动及焦点恢复。
- 参考弹窗可出现底层密集文字透穿。沿用玻璃的体积、边缘高光和空间层次，但阅读面增加足够散射与遮蔽，按实际底图检查可读性。全局玻璃不等于全层高度透明。
- 不复制参考中的倾斜角度、滚动劫持、播放器、旧部门映射及小字号；硬要求仍来自当前 tokens 与 01–11。
- 样例台账与站点版本可能不同；展示数量、流程和效益描述必须服从当前任务材料。需求预期不能改写为实测效果，也不把参考业务事实当成本任务输入。

不新增 ARCO 的框架或动画库依赖来“证明借鉴”。已有引擎可实现这些机制时直接使用；确需引入库先核对其当前许可、接口与宿主兼容性。

## 两个外部示例库的限定取舍（A04 R11）

本轮实际Chrome查看了 [001 Aurora Glass](https://miaai-lab.github.io/Claude-Opus-5.5-100-HTML-Files/001-aurora-glass.html)、[050 Loader Atelier](https://miaai-lab.github.io/Claude-Opus-5.5-100-HTML-Files/050-loader-atelier.html) 与 [MotionSites](https://motionsites.ai/) 首页；每页初段6.5秒，不宣称看完100例或每段完整循环。

- 001：借鉴程序化光场与阅读面分层、指针高光和轻倾斜；不复制暗夜配色、发光标题、疗愈文案、声音或启停控件。
- 050：借鉴同一载体由形状变化表达状态。只作为局部动作参考，不能把loader当业务电影；不复制暂停、重播、复制CSS工具条与小字号。
- MotionSites：实际首屏包含视频预览，不据预览断言其内部使用连续DOM形变。它是审美候选库，不是医学叙事/可编辑/真实交互的验收证据；主实现仍按06并重点参照已核实ARCO机制。

只借鉴机制，没有添加库依赖或复制整页源码；全站光场豁免仍必须由本产品真实运行及生命周期证明。
