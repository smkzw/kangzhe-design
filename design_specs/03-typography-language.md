# 03 字号、中文表达、观点与引用

## 字号合同 TYPE-01
正文默认 15pt / 20px；正文最低 12pt / 16px。卡标题 18pt / 24px；页标题 24pt / 32px；观点 18–20pt / 24–26.67px。页脚、参考行分别使用固定角色值，不借这两个例外容纳正文。仅参考文献允许 8pt / 10.67px。所有正式图表轴/图例、表体、标签与注释若承载听众必须读的内容，最低仍为 12pt / 16px。旧 14px ultra、15.5px 入排、12px chip 等漏洞全部移除。

**同页同角色只允许一个字号、一个行距和一套间距**。页面可以有标题/正文/数值/文献等合法层级，但不能“第一张卡 20px、第二张 18px、第三张 16px”。compact 是整页正文档，不是挤不下的单卡开关；降档须在 page-plan 中写原因。不同页同一种卡的角色档默认保持，不为凑页数反复变动。

HTML-PPT 的 px 指逻辑画布单位，不随 viewport/DPR 改变；由上游统一缩放。PPTX 必须设置适当的 Latin/East Asian 字体域，中文 run 保持微软雅黑；纯数字/英文 run 可 Arial。字体不可用写环境失败，不静默宣称字体观感通过；不得分发字体文件。HTML 站点可响应式调整，但正文不能低于 16px，阅读宽度和整体场景宽度分开控制。

## 容量溢出的固定处置顺序
确认文字是否重复/无关 → 精简非事实性修饰 → 扩大有用区域或重排网格 → 主内容/明细分层（关键限制仍在主层） → 拆页 → 最后才选择全页 compact。禁止逐卡缩字、压缩单卡行距、CSS scale 文本、字号动画救容量、ellipsis、line-clamp、隐藏裁切或将必要限制只放 hover。

同一连续段落在 PPTX 内用一个 text frame 的多段落/多 run，而不是每行一个文本框。同级并列卡的标题基线和首行基线一致。统一内边距；行距不靠插入多个空段落伪造。

## 标题与五类文字分工 COPY-01
| 角色 | 正确职责 | 示例 |
|---|---|---|
| 页标题 | 简短章节/内容名称 | 入排标准；研究设计；XX研究结果；安全性结果 |
| 卡标题 | 内容类别、指标或对象名称 | 研究人群；主要终点；治疗期间不良事件 |
| 正文 | 原材料支持的事实、关系、限定与必要解释 | 每条表达一个完整意思；保留数字和条件 |
| 可选观点句 | 听众应理解的本页含义 | 解释证据的含义或实施要点，而非重复一串数值 |
| 讲者备注 | 有帮助的解释、限定、衔接 | 不将整页文字再读一遍 |

页标题禁止冒号 `:：`、破折号 `—–`，不写结论/趋势句。项目代码中本来存在的半角连字符不是破折号，不应被误改。标题不能靠缩字或省略号塞入固定标题框；优先短写研究名称，必要的研究全称放正文。

不合格：“研究结果：疗效显著提升”“入排标准——精准识别人群”“三重优势助力突破”。
合格：“XX研究结果”“入排标准”“研究药物”。

## 观点句 COPY-02
每页先明确 `takeaway: null` 或文本+材料依据。研究基本信息、流程总览、原文规则表等页面完全可以没有观点句；不要给每页分配一个强制结论槽。没有观点句时让正文回收该空间。

存在时：只传达一个被材料支持的含义；不新增临床外推、不暗示因果、不把方法学警告包装成结论。短到能在居中玻璃强调面内清楚读完；水平、垂直均居中；比正文显著大一档。重复卡内数字、逐项重新报数不算合格。观点不是“本页展示……”或“请重点关注……”等审稿指令。

例如在无额外证据时，不能把“治疗组改善量大于对照组”自动升级为“长期获益更好”。若材料只支持描述性资料，不造一个强调句凑版式。

## 中文 COPY-03
面向严肃使用场景。优先自然的中文名词和完整短句，不用直译词序、不用空泛的大词、不用向工程 Agent 说话的口吻。卡标题不写“输入/输出/抓手/赋能/解锁/打通/闭环”来代替具体医学含义；但材料确实在讨论接口、输入数据或技术闭环时可按专业含义保留，不能词表机械误删。

英文缩写首次出现按材料和受众需要解释；既定医学名称、研究编号和量表名保留。未给中文译名的专名不臆造。不要无必要的“原生”“硬核”“一键起飞”“拿捏”“全面领先”“颠覆”。不使用拟人化宣传腔替代科学机制。

原文规则类内容：保留原编号、逻辑连词、阈值、时间窗、例外条件。概览页允许明确标注为概览，但不得冒称完整原文；完整培训内容需要原文时可拆页，不能为了变短改变规则。生成稿不自动对附带临床资料进行医学纠错。

## 强调 COPY-04
普通重点首先加粗。深红 #C00000 只用于真正改变理解的关键结论、风险、阈值、关键否定或需确认内容；不是一切“重要”都染红。观点通常一组主红词，最多两组；普通 bullet 最多一组，单页红面积仍受品牌预算限制。不得强迫每卡至少一处红/粗/下划线。颜色不承担唯一语义；红色风险要有文字说明。完整句子不作大面积红色广告。

## 引用 COPY-05
受众页面只为 **外部科学论文** 和 **权威指南、共识、指导原则** 设置参考文献式标注。对内部方案、IB、会议纪要、台账、用户附件、未规范命名文件、内部数据汇总，以及普通新闻/网页/登记数据库等其他来源，默认不展示“来源于……”或文件名。

这不是删除科学限定：研究名称、人群、时间点、终点定义、分析集、样本量、单位、估计量、CI/SD/IQR、必要版权署名仍应保留。论文对应的期刊信息、DOI/PMID等在已核实后写；不凭空补作者、卷页或 DOI。权威性与文献类型由实际来源判断，不因文件后缀是 PDF 就视为指南。

私有 `source-ledger` 仍记录所有数字/事实的材料位置和版本，供校核，不复制到受众页。法规或授权素材确有不可省略的法律/许可署名时，以相应义务为准，单独记录原因；不能借此恢复所有来源的泛化强制标注。用户要求公开技术研究报告时，其引文遵守该报告任务，而不是套此 PPT 来源展示简化规则。

## 纵向利用 TYPE-02
先分配标题/正文/观点/文献的真实空间，再排卡。内容页主体通常占用正文可用高度的 70%–92%，这是预警阈值而非强迫填满的硬分数。正文卡的文字长期只占上半部时：调整卡高、增加合理段间距、按语义分组、将短统计卡整体居中；不拉大字间距或插入空卡凑高。

记录可见内容的联合包围盒、上/下净空、各卡内容重心。上下净空差超过可用高 20% 或同级卡差异显著时必须人工复核。标题页、极简结论页、原图比例留白有独立理由。**背景、透明节点、阴影、装饰与隐藏明细都不计入内容占用**。文字墨迹检查与结构盒检查并用，不把 line box 当作真实字形。
