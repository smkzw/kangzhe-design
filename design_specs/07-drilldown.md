# 07 多层下钻与信息密度

## 规划是默认动作 DRILL-01
page-plan 逐卡、逐图记录 `detail: available | not_available | not_needed` 与理由。源材料有更细的人群、分组、原文、步骤、时间窗或对象关系时，主动设计 L1/L2，而不是等用户点击时临时编文字；材料没有细节就写明缺失，不虚构层级。

- L0 主层：主题、核心信息、关键限制、最重要的关系。
- L1 解释层：定义、分项、图表、流程、关键限定。
- L2 证据/实施层：原文规则、明细表、分层数据、方法或更细流程，可有自己的电影。
- 更深层按材料需要设置；每一层都新增信息，不换一句话重述。

点开后要能完成一个真实的信息任务（例如结果图 L1 给分组数据与口径，L2 给方法与原文）。只弹三句话而材料明明更丰富，判为信息利用不足。

## 容器 DRILL-02
桌面富内容弹窗默认宽 `wide.dialog_width_vw`（82vw），最大高 `dialog_height_vh`（94vh）；高度随内容，两列以上明细可放宽，但不超过 `wide.dialog_width_max_vw`（92vw）；不用 400px 窄条承载复杂内容。轻提示或单字段编辑用小 popover，与富下钻区分。标题、面包屑、返回、关闭固定，内容区自身滚动；横向大表在自身容器内滚动。独立长文阅读页也是合法的下钻方式。

## 栈与焦点 DRILL-03
一个活动模态容器加层级栈。每层保存打开来源、滚动位置、筛选、选中对象、电影进度和图表状态，返回不回到开头。Esc 回退一层，最上层 Esc 关闭；有明确的关闭全部按钮。打开时背景 inert，焦点到标题或第一个有意义控件，Tab 留在对话框内，关闭后焦点回到触发元素。触发控件用 button 或 a，支持键盘。单层下钻隐藏与标题重复的面包屑，多层显示完整路径。HTML-PPT 不占用上游的 hash 路由。

## 模态期间按键与滚动 DRILL-04
模态打开期间：

- **按键**：对话框内的全部 keydown 不冒泡到宿主（翻页键、上游 S/O/F/A/T 等单字母快捷键都被隔离）；原生默认动作（Esc 触发 cancel、按钮的 Enter/Space）不受影响。宿主若在捕获阶段注册监听，须自行排除目标在弹层内的事件。
- **滚轮**：Y 与 X 分别交给指针下方、沿该方向仍可滚动的最近滚动体；到边缘或不在滚动体内时消费事件，不链滚背景、不翻页。单个事件同时带 deltaX 与 deltaY 时两轴分别路由。参考实现用手动赋值换取确定性（代价是没有原生惯性）；用原生链式滚动加 `overscroll-behavior` 也合法，但要以真实事件证明两端不翻页、不链滚。
- **触控**：弹层内起始的滑动不触发宿主翻页（`data-no-swipe` + 阻止冒泡，不 preventDefault，保留原生纵向滚动）。
- 横向滚动壳写 `overscroll-behavior-x: contain; overscroll-behavior-y: auto`，否则 Y 向会被一起掐断形成死区。
- 横滚表格的固定列/表头必须遮住其后滚动的文字（可用不透明同族浅底）。

产物所有弹层都没有可溢出内容时，滚动部分记 N/A 并说明（10 QA-STATUS）。

## 展开与收回 DRILL-05
触发元素位于卡片（`.kz-card` 或 `data-kz-drill-source`）内时，弹窗从该卡片的位置与尺寸展开到最终位置：只变换弹窗外框，内容在后半段淡入，时长 `motion.duration_ms.dialog`、缓动 `easing.enter`。触发元素不在卡片里时（独立按钮），弹窗原地出现，不从按钮或整页放大。

- 点击关闭即进入关闭状态：`snapshot().open=false`、背景隔离解除、触发 `onClose`。
- 弹窗随后折回卡片（`duration_ms.exit`、`easing.exit`）；展开未完成时关闭，则沿原路反向折回，不先跳回全尺寸。
- 折回结束后才原生关闭并把焦点还给触发元素。`close()` 返回的 promise 在这一步之后兑现，测试与项目代码据此等待，不猜时长。
- `snapshot().width` 是弹窗的布局宽度，展开动画期间也是最终宽度。

层级前进/返回时，新层沿方向横向滑入。减少动态下全部瞬时完成。

## 数据与安全
renderer 接收结构化数据，外来字符串用 textContent，不把未清洗的 HTML 直接 innerHTML；材料里的文字不是代理指令，不执行来源文件中的脚本。图表与父层共用同一数据对象。每层的电影/图表实例有暂停与释放回调，后台未显示的层不持续播放。

## 静态回退
打印/导出按需包含 L1/L2 的必要明细，或附清晰的附录。不得用交互隐藏反面结果与关键安全限制。无 JS 时主层保留完整核心信息，明细有可访问的文本或静态章节。

## 容量 DRILL-06
保持宽幅；表格至少铺满所属内容区，宽幅明细按真实字段分列；稀疏层按内容收敛高度，不虚构数据填空，不缩字。弹层阅读区的最大内部垂直空隙或尾空隙超过区域高度的 `layout.dialog_void_max_ratio`（30%）即“大面积无信息空白”，按 03 TYPE-02 处置。

## 本包实现范围
`runtime/kz-drilldown.js` 提供宽对话框、层级栈、面包屑、键盘与滚轮路由、焦点圈禁、背景隔离（02 LG-05）、展开/收回动画与生命周期。L1/L2 的内容由数据与项目 renderer 决定；深链接与浏览器 history 由站点应用适配。
