# 02 统一 Liquid Glass 材质

## 这是康哲化的材料语言，不是假称 Apple 原生材质
采用透光、边缘折光提示、空间层次、柔和阴影和连续形变；不是把一张透明白卡叫做 Liquid Glass，也不是全页高强度模糊。Apple 的原始设计面向控件和导航；本包应用户要求扩展到汇报卡片，并通过高可读玻璃面控制高密度内容。此扩展是本设计选择，不声称逐条遵守 Apple 界面规范。

## 单一材料、三个阅读用途
| 用途 | 材料表现 | 不可破坏的底线 |
|---|---|---|
| 主视觉/叙事载体 | 较高透光、可感知的圆润厚度、暖橙边缘反射 | 避开文字和数据保护区；不替代正式 Logo |
| 正文卡片 | 较高白色散射、薄的完整中性边界、局部弧形高光、柔和空间影 | 全页同族；不能一半实色扁卡一半夸张玻璃 |
| 数据阅读面 | 同族玻璃外壳，内部安静、近白、无移动反光的阅读区 | 数据刻度与比较不折射、不透视、不变形；不再叠一层 blur |

这些是同一材质的密度调整，不是三个可自由混用主题。每页先选一个 card density；同级并列卡一致。颜色、圆角、白色散射和阴影来自 tokens；局部阅读遮罩不把整个组件退回旧扁平卡。

## 组成配方
一个可识别的正文玻璃卡至少包含：半透明白/微暖渐变面、连续中性薄边、局部高光（长度不超过该边的约三分之一）、一层低强度环境阴影。高光不是橙色通长横线。卡片的 tint 只占少量局部反射/编号/图标；不要四部门四块整卡彩底。

HTML 的 `backdrop-filter` 是模糊/色彩处理，不等于物理折射。规范默认提供 CSS 光学近似；WebGL 真折射只能作为已验证增强，不得成为阅读或运行前提。禁用嵌套多层毛玻璃；玻璃内的小字段、表格行、chips 采用同材料薄覆层而非再次模糊。无滤镜能力时提高散射、保留薄边与高光，明确记录兼容降级。

PPTX 使用 **原生可编辑透明填充、渐变、圆角与阴影**，必要时加局部独立光学贴片。半透明填充应能在编辑器里调整。贴片不包含卡内文字、标注或统计信息，不得把整卡栅格化。动态背景折射、真实鼠标视差不是 PPTX 的本地能力，不得宣称实现。渐变/阴影的可用字段以已安装 PPT Master 的接口为准，禁止添加它不认识的 SVG filter 或 JSON 属性。

## 色条绝对禁令 LG-02
无论旧组件、新组件、主题、轨道、密度、风险卡、引用卡，均不得使用沿一条边覆盖卡宽/高大部分长度的彩色条作为装饰。包含：border-left/top、独立 rect、伪元素、box-shadow inset、linear-gradient 伪装、带颜色的通长底边。不允许“身份色必须保留”“存量可保留”豁免。

可以使用短编号、文字色、语义图标、局部点状光晕、局部弧形高光。卡片四周中性极细光学边界不属于彩色身份条。甘特条和统计柱是数据编码，不是卡边装饰；正文页固定橙线是保留的品牌 chrome，不应被误杀。检测器必须结合 **对象角色与所在几何位置**，不能简单禁止所有长矩形。

## 圆角与空间
正文卡、中型图表壳、对话框分别用 tokens 的半径。外壳/内层圆角按内边距同心缩减，不出现外圆内尖。过度胶囊化会吞掉内容面积，卡片不一律药丸形。自由形液态载体只出现在有语义的电影/hero 中。阴影不超过规定 alpha，禁止黑硬影、霓虹边和高饱和大光晕。

## 交互
hover 光源从指针位置移动，文字本身不闪烁；倾斜由独立内层承载，幅度限制在 ±10°。表格、图表测量面及甘特编辑面禁止透视；允许外壳发光，不让坐标变形。拖拽/选字/键盘编辑时关闭宿主 tilt；触屏与 reduced-motion 不要求倾斜。正文页双菱形浮动幅度很小，基准坐标不改，冻结态回到基准。

## 视觉反例
不合格：纯白扁卡配左橙条；橙色胶囊满屏；玻璃外壳上再叠四层半透明卡；文字背后有穿过笔画的高亮折线；黑底“高级感”；真实数据图做成透视立体柱；静态图只靠强 blur 隐藏背景冲突。
合格方向：浅白光场＋少量橙黄折射提示＋同族玻璃卡＋稳定深色文字＋平直准确的数据面。视觉审阅要同时看未 hover、hover、动画中段和冻结态，不仅看最漂亮的帧。

## LG-03 双菱形是固定品牌资产，不再重新设计
唯一外观以用户明确指定的原生标记为准：`assets/header-mark/source-native.xml` 保存从参考 PPTX 提取的四个原生形状。橙色大形在后、黄色小形在左下前方；原始倒角、坐标、渐变、阴影、softEdge 与叠放顺序全部保留。资产内数值是这组标记的唯一权威，tokens 只登记路径、身份和 hash。不用普通四边形近似，不增加深色侧折面、白色高光线、透明玻璃片、光晕或其他装饰，不随部门换色。通用玻璃卡材料规则不改造这组品牌对象。

PPTX 在真实 ppt-master 导出后按 `adapters/ppt-master.md` 直接绑定这四个原生对象；不得用截图、SVG 图片或自行重建的近似形状冒充照搬。保留上游原件，记录替换对象 ID 和原生结构校验。HTML-PPT 用 `tools/brand_fragments.py` 从同一资产生成的 SVG，保持同一几何、颜色和叠放；浏览器阴影抗锯齿差异须通过实际截图审阅，不能反向修改 PPTX 原件。

HTML 只对整组施加轻微竖直浮动，幅度与周期来自 motion tokens；当前为向上 2px、6.4 秒一周期，无左右漂移、旋转、倾斜、相对错位或呼吸缩放。不加播放控件。减少动态、preview、print 和冻结态回到基准；非活动页/后台暂停。标题、横线与 Logo 保持静止。旧例中异相浮动和额外折面要求已被本次用户固定样式要求取代，不得继续引用旧例作为验收标准。
