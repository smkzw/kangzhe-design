# 10 质量门与放行

## 先分结果类别
硬门 fail 不能用美观高分抵消。warn 必须有理由与影响范围，pending 表示未测，不是默认 pass。交付记录逐轨、逐功能列出，禁止“全部通过”但没有证据。

| Gate | 内容 | 最小证据 |
|---|---|---|
| G0 输入与引擎 | 事实清单、页型、所选官方引擎、版本/commit、能力发现 | 计划、源定位、真实工具回执 |
| G1 品牌 | tokens 一致、官方 Logo hash、部门映射、chrome 几何 | token 派生检查、XML/DOM 与逐页图 |
| G2 语言与排版 | 主题标题、可选观点、同级同字、字号地板、无翻译腔/生产口吻 | 静态 lint＋语义审阅；全页与局部 |
| G3 生图前 | 保护区/扫掠区与主题资产计划 | mask/overlay、page-plan |
| G4 生图后 | 实际调用、裸图与合成页、裁切、颜色、冲突 | receipt/hash、逐页截图、问题坐标 |

## 阶段化检查，不每改一句就启动全部模型
预检一次发现缺依赖；布局草图阶段检测容量和保护区；生成阶段批量完成同一风格资产；组件阶段跑小型确定性测试；每个完整语义里程碑再跑浏览器/视觉审阅；最后完整回归。不要对每个 CSS 小改动重启大模型、安装依赖、渲染全部项目。

## 几何与文字
HTML 用真实 computed style、Range/文字节点矩形、容器 client/scroll 尺寸，检测盒越界与字形风险；PPTX 用 OOXML 属性与渲染共同判断。只看“页面没滚动条”不够。祖先与子节点本来包含不是碰撞；背景的图像边界跨区域不代表失败，但其中可见结构穿过正文/数据阅读区按 IMG-05 拒绝；业务连线按其对象合同检查，正文块/标签重叠不是允许行为。

G4-BODY：正文背景单独按 IMG-05 审核，至少提交文字卡、统计图、表格/甘特三种实际合成。中央无可辨认装饰结构、边缘不占固定 chrome 槽，原有卡片与数据外壳保持同族；不以新增玻璃层数抵消背景失败。裸图通过不等于正文页通过；视觉与真实像素分辨率分栏。

动态检查记录有效祖先透明度、可见文字 Range 和所属阅读区，区分隐藏占位与真正裁字。 `KZLayoutQC.inspectTextBounds(readingZone)` 提供四边界与祖先透明度检查；对电影以实际 carrier/reading zone 调用，在正常全周期定时采样，不只检外层整卡。EMPTY 不能计为内容通过；任何非零透明度的越界仍需处理，显式阈值跳过可绘制文字时返回 REVIEW_OPACITY。中间祖先的矩形裁切也检查；clip-path、变形或透视的非轴对齐区域另做视觉核对。此辅助检查适用非滚动阅读区；合法局部滚动表格另验可见区域和所有列实际可达性，不能要求全部滚动内容同时在视口内。下钻返回位置断言在实际打开动作前取值：若自动化点击先 scrollIntoView，须在它之后、push之前记录滚动位置和焦点；不能拿更早的人工设定值制造失败。表格局部横向滚动只有在真实拖动后能读到全部列、列头对应保持清晰时才算可访问，不能凭 overflow:auto 声称通过。

同角色字体收集全部 run/DOM，不按卡内最小值各自通过了就放行。全文校验圆角、填充 alpha、阴影、Logo 位置、红色语义；不把 ECharts 的轴线/数据条当装饰色条。

`inspectCard` 仅测量非滚动卡片的内容分布；发现实际局部滚动区时返回 NOT_TESTED 并列出 scrollports，不误报整张滚动表格越界，也不能因此标为通过。此类卡片须另取可见 scrollport 的文字/数据边界，实际滚动验证全部行列与列头对应，再独立报告卡内空间分布。

图表内容计数来自实际 ECharts 已解析系列数据，不以空 canvas 或未处理 dataset 声称有内容。默认使用随包全局 ECharts；模块化宿主调用 `inspectCard(card,{chartLibrary:实际导入的ECharts})`。已绘制但无法取得实际实例/系列数据时为 NOT_TESTED，不假 EMPTY 或假通过。零面积 legacy clip 的辅助阅读文本不进入视觉 bbox；部分裁切和非矩形裁切仍需专门审阅。

纵向诊断用有效文字/数据联合 bbox 与上下空白；不能把 564px 空壳算利用率。先说明根因再改，不以“填满高度”为由加无意义观点或重复卡片。

G5-NESTED：对电影最大展开态中的每张子卡/阅读组也分别执行03 TYPE-02，不用父载体联合bbox掩盖内部空白。记录该对象实际T/B/H/R、布局模式和普通态帧位置。短卡居中是允许模式，需证明居中和卡群平衡；顶部空白、底部空白及卡片外的正常留白分开测量。独立审阅若把卡外空白误判为卡内拉伸，按实际rect/Range和源码裁决，保留原审。

阶段计划须指出完整阅读/最大展开的进度区间，普通态在该区间实际取样，另检查全部非零alpha文字与迁移容量；诊断seek单独标明，不能代替自然周期。开始观察时若已在中途，至少观察完整时长并跨越回接，直到取得各阅读阶段，不因看见一次wrap就提早结束而遗漏片头。

## 动画检查
静态截图与动态审阅并列；固定截图种子与进度方便回归，但不得只测试 `?qc` 冻结模式。必须有普通观众运行态。对每个场景取开始/中间/结束，并检查所有迁移期间的保护区。导出/打印再测完整性，退出后不永久冻结普通打开。

G7-INIT：从普通观众URL进入每个含动态的活动页，捕获真实pageerror/相关资源错误，确认所需组件完成挂载。使用本包Film时核对实际ready和有限进度或实例snapshot，然后观察自然推进、完整wrap及离去复入；其他时钟提供等价真实状态证据，不凭库文件存在通过。异常、undefined/NaN、零采样、未挂载或空图一律不能计PASS。动态组件错误可能中断其后的chart/gantt启动，所以同时断言数据揭示结束后的实际图表系列/表格真值，而非只有可见空canvas。capture/print副本跳过初始化或直接finish的结果另列，七页PNG导出成功不能关闭普通态初始化缺陷。

QC仪器在每页/每场景结束即耐久写入已观测结果和source hash；异常终止保留已有结果、真实退出码与错误，不以末尾单一JSON写失败抹去所有前测，也不靠补写全绿报告补齐未执行检查。修仪器与修产品分别归因。

## 可编辑性
PPTX 至少抽样编辑一段中文、一个表格格子和一个甘特条（存在时），保存重开检查。图表对象按 canonical data、缓存和嵌入工作簿逐值核对，并在 PowerPoint 检查原生图形渲染；形状型甘特注明不具日期联动。光学装饰图片合法，但一整页/整卡栅格化不合法。

HTML-PPT 必须通过官方缩放/深链接/箭头/演讲者窗口；编辑表单或 modal 中的按键不触发翻页。不能用本包 demo 通过替代该项。

## 证据结构
每项至少：rule_id、status、artifact、page/scene/object、expected、observed、method、environment、evidence_path、hash（文件存在时）、owner、next_action。未执行写 pending 和原因。VLM 分数要带模型/版本/提示/输入帧/原始回复，生成者和评审者身份隐藏。模型报告的“我看过”不算访问证据。

盲审帧包必须可解释所见范围：记录 viewport、page/scene、普通态或静态态、时间/进度、页面与弹层 scrollTop/clientHeight/scrollHeight、是否主动滚到电影。包含下钻顶部、电影所在中段和底部，不能只交滚动中段让评审猜首行是否存在。评审可以不知道生产者和修复历史，但不能缺少判断所必需的页面位置。静态截图只能证明可见外观：不得由“未出现在此截图”推断 DOM 不存在，或由“玻璃感弱”推断没有 backdrop-filter。疑似缺失项先由 owner 对照源码及真实滚动复核；保留原判断、复核证据和 JUDGE_ERROR，不覆盖原始报告。

本次范围不提供原生 Excel 支持，不调用、打开、重启或修复 Excel，也不以 PowerPoint“编辑数据”启动 Excel 作为验收门。PPTX 仍须通过 ppt-master 输出原生可编辑对象，核对 canonical data、图表缓存和嵌入工作簿结构，并在 PowerPoint 中检查渲染及文字、表格、形状的编辑保存回读。结构核对不等于原生 Excel 编辑验证；既往 Excel 异常仅保留历史记录，不阻塞当前验收。新产物的其他检查不得继承旧试件结论。

## 放行等级
- **设计规范可用**：文档/参数/契约自洽，基础工厂和本地测试可运行。
- **组件已验证**：具体列出通过的 DOM/数据/单元测试，不扩展到其他环境。
- **轨道已验证**：该轨官方引擎 E2E 与目标运行环境都有证据。
- **正式业务产物可交付**：逐页事实/视觉/来源/图像/编辑/讲稿都已复核。

本包版本号 6.0.0 指规范重构版本，不代表全部能力、所有模型与所有 Office 已得到正式放行。当前状态入口为review/CURRENT_STATUS.md；LOCAL_VALIDATION.json及旧轮次只记录各自历史范围。

## A03不可由组件测试替代的交付门
- G5-LAYOUT：每页每卡按03输出layout_mode、Range有效bbox、上下净空、重心；审阅预警处置，不能只数容器高度。
- G5-WIDE：16:9/2:1/21:9/超宽真实viewport的deck边界贴视口；背景无两侧空带；内容网格宽度达到品牌锚范围。body进度条、未使用两侧涂色不能充数。打印与preview另测。
- G5-FACET：仅适用于 PPTX/HTML-PPT 的固定资产同源校验：PPTX 四个原生形状除唯一 ID 外与批准资产结构一致，顺序及坐标一致；HTML 同一几何/颜色/前后关系，只整组竖直微浮动，两个实际时刻和 RM/冻结态复核。不接受自行加侧折面或白色高光线。
- G5-MARK-SCOPE：站点式与流式 HTML 的实际 DOM 和渲染画面均不得出现 PPT 双菱形；移除其挂载、占位与装饰样式，保留正常站点导航和官方 Logo。历史冻结试件不覆盖，新增候选另行复核。
- G7-OBJECT：实际交付页每个卡片/流程/数据/识别件的motion manifest对照真实轨迹；库存在不等于接入。普通态进出/hover/float与静态完整性分别验证。
- G4-ASPECT：真实生成回执、actual_size和源图比例；crop后保护区域复核，不以视觉拉伸充当生图。
- G10-CAUSAL：新规范hash与对照输入冻结，同工具权限与整项预算；owner修复与模型原件分离；保留集不得在迭代中反复调参。未关闭失败继续列出。

- G7-NO-PLAYER：普通页、章节、首尾、L1/L2和返回态均无可见播放/暂停/重播/进度滑杆/时间码/“开始播放下一页”。首次打开和正常翻页即可看到自动动态；没有控件不等于没有动画。业务筛选、详情和甘特编辑控件不在删除范围。

- G7回归：清除进度滑杆仅可匹配`input[data-kz-progress]`等控件，不可匹配电影根节点的同名状态属性。清理后须同时检查载体仍连接、时钟递增、正常周期回接；隐藏整段电影不算去播放器通过。

A04 四轨放行：依 agent/EVALUATION.md 第9节逐轨查轮次与证据；最终冻结包两次完整回归无新增缺陷。局部组件通过不能清空上游、原生Office、独立视觉和跨模型待验项。

G5-DRILL-CAPACITY：逐层核对宽幅利用、内容适配高度、表格与容器宽度、底部无信息净空、标题/面包屑重复；横滚最左/最右两端与键盘焦点态核对固定列遮罩是否穿透。可达性通过不能代替文字遮挡和空间密度审阅。
