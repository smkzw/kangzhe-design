# 08 可编辑甘特与时间语义

## 两种“可编辑” GANTT-01
HTML-PPT 与网页中的甘特必须支持实际交互：选择任务、拖动整条、拖两端调整、在编辑器里精确修改年份/季度、即时同步、撤销与还原。编辑器按需出现：默认只显示图表并占满卡宽；点选任务条（松开后）、在图上按回车或方向键、或接口 `select()` 时，编辑器在右侧展开，图约 3/4、编辑器 1/4；“完成”或 Esc 收起并把焦点还给图。空间不足时编辑器展开在图下方，不缩小正文。有未撤销的修改时，“已修改”提示与撤销、还原按钮在收起状态下也保留。

PPTX 中的“可编辑”是 PowerPoint 编辑模式下的原生时间条、标签、轴和说明，不是浏览器里的输入框与吸附。ppt-master 的原生 chart 类型不含甘特，用可编辑原生形状与文本输出。需要时同时交付交互 HTML 与 PPTX，并写明同步边界。

## 单一时间数据 GANTT-02
数据格式见 `schemas/gantt.schema.json`：

- 任务：`id / label / start / end`，可选 `owner`、`department`（表达部门身份时取部门色）、`status`、`color`、`dependencies`、`start_known` / `end_known`。稳定 id 不用显示名充当主键。
- 默认季度粒度，整数 quarter index：`index = year × 4 + quarter − 1`（`KZGantt.qindex`）。内部区间为 **[start, end)**：界面上的“结束季度”是最后一个包含的季度，换算为其 index + 1。例：2026Q1–2026Q3 是 `[8104, 8107)`，长度 3 个季度。
- 源材料是明确日期时保留日期粒度与时区规则，不擅自四舍五入成季度。没有真实结束日时 `end_known: false` 并在界面写“待定”，不编造时长（参考组件只实现季度粒度，日期粒度须项目实现）。
- 引用既往研究资料的时间条默认只读；允许调整时建立独立的“计划/情景修改层”，原始证据层不被覆盖。

## 手势与表单 GANTT-03
整条拖拽保持时长，左右边缘调 start/end；指针通过图表坐标反变换，不能把屏幕 dx 直接当季度偏移（HTML-PPT 有整体缩放、浏览器缩放和 DPR）。用 pointer capture，pointercancel / Esc 回退本次拖动，微小位移视为选中。吸附季度、夹在轴边界内、至少一个季度；禁止负时长、start≥end、NaN、越界和重复 id。左右端命中区宽 `gantt.handle_px`（14px），短条按条宽的 `gantt.handle_short_ratio` 收窄，仍须能分别拖动两端；密集相邻条防误选。编辑时图表面不倾斜。

点击选择后编辑器同步显示起止年与季度；方向键移动一季度，Shift+方向键调结束季度；表单提供等效功能。输入无效时给具体错误，不清空原值也不悄悄夹成另一个日期。

## 变更 GANTT-04
一次完整拖动是一条 undo，不是每个 pointermove 一条；表单确认是一条 undo；撤销回原始状态后 dirty 清零；“还原全部”回到原始数据。有变更时才出现“已修改 / 撤销 / 还原”浮层（叠在甘特容器内，不撑高宿主）；没有变更时不常驻。默认不提供面向受众的导出按钮；序列化 API 只用于测试与应用适配。持久化默认关闭；用 localStorage 时处理权限失败并给恢复/丢弃选择。修改不改写源文献或原始资料。

## 动画与编辑互斥
首次出现时条形按 05 CHART-04 的数据缓动依次延伸（上到下小错峰），基于冻结的原始目标数据。用户开始选择、拖动或输入时立即结束揭示、呈现真值并进入编辑；返回页面不重播覆盖修改。缩放和重绘后重新布置把手，不保留旧屏幕坐标。

## 实现范围
`runtime/kz-gantt.js` 是季度、单轴参考组件（ECharts custom series）；它读取 `color`、`department`，不渲染 `status` 与 `dependencies`；遇到未知端点（`start_known` / `end_known` 为 false，schema 允许对应端点为 null）直接报错，由项目另行标示“待定”，不让参考组件编造时长。日粒度、依赖自动调度、多人协同、写回源材料都不是已实现能力，不得写进完成清单。
