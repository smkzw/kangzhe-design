# 流式 HTML 轨道

按文档/电子书阅读组织章节，可有固定目录和章节锚点；不是一串固定 16:9 幻灯片。左上双菱形仅限 PPTX/HTML-PPT；流式 HTML 不出现这组装饰，也不保留其空占位。首页和一级章节开头以自动连续电影建立概览，下方展开完整分析。正文允许自然阅读高度，不把所有段落包成等高卡。

继承站点的宽屏策略：电影/关系图/统计图区尽量用宽，长正文限制行长并可用双栏或阅读栏＋侧注。不能因为文字行长受限就把整个页面都缩到中间。章节电影离屏后停帧，阅读下方段落时不让后台大场景持续耗资源。

主动设计有材料依据的多层下钻。一级卡为摘要，二级容器可有多卡、多图和原文，必要时进入三级；dialog 的宽度与内容密度匹配。打印态保留全文与关键明细，不让折叠后只剩标题。

本轨使用 03 的引用显示规则；不是旧版“所有外部网页都必须脚注”。标题与小标题保持内容名称，观点可在导语/结论段表达，不把所有标题都改成广告式断言。没有人类演讲任务时不强制生成逐字稿。
