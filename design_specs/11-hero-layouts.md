# 11 封面、目录、章节、尾页固定形态

## HERO-01 固定合同
PPTX 与 HTML-PPT 在16:9基准态共用 `tokens.hero_layouts` 的1280×720、版式ID、文字框、Logo框和字号。HTML宽屏态保留形态与字号层级，按adapter的左右锚定/网格延展；PPTX按96 px/in与72 pt/in换算。禁止各轨重新设计、逐页缩字号、随意居中/左对齐切换。正文页的页眉页脚仍按原合同；四类非正文页只采用本合同的 Logo，不叠加正文页 chrome。

| 页型 | 固定形态 | 专用字号 px / pt |
|---|---|---|
| cover-01 | 左上官方 Logo；左对齐大标题，最多两行；其下副标题、单位与日期；下部生成主视觉 | 主标题 56 / 42；副标题 28 / 21；元信息 20 / 15 |
| toc-01 | 左上“目录”或“汇报章节”，右上 Logo；三列玻璃卡，最多两行；不足一行居中排布 | 总标题 48 / 36；序号 40 / 30；条目标题 32 / 24；说明 20 / 15 |
| section-01 | 右上 Logo；左上大号两位数字，下面独立一行章节名称；下部生成主视觉 | 序号 112 / 84；章节标题 60 / 45 |
| ending-01 | 左上 Logo；左侧大号结束语，下面可选致谢与单位日期；下部生成主视觉 | 结束语 104 / 78；副标题 28 / 21；元信息 20 / 15 |

完整几何和图片摆放只读 tokens。表内数值是便于阅读的对应说明，变更时必须同步 token 与派生产物。文字行高固定 1.25；目录卡标题/说明各一行。首尾页按角色使用墨色或正文灰；章节号和目录号允许品牌橙。标题不加渐变填充、扫光、拉伸、发光或投影。

## HERO-02 容量与变化边界
固定的是版式结构、对齐、文字层级和位置，不是医学内容、日期、城市意象或一套永不变化的图片。封面超过两行先缩短展示名称，完整名称移至后续研究基本信息；不得改小字号。章节名称超过一行先简写，完整称谓在正文保留。尾页结束语应短至一行，可用“谢谢”或符合场景的简短文字。

目录最多六项；七项及以上拆为连续目录页。每行固定三个等宽槽，末行不足三项居中排列；只有一到三项时使用第一行，空出的区域保留给生成主视觉。不得加空卡凑数。目录说明可为空，不编造内容。所有目录卡使用同一种中性边缘玻璃材质，不按序号轮转部门色。HTML 的目录允许跳转；PPTX 可设置原生内部链接。

目录卡阅读层只使用 `tokens.hero_layouts.toc.reading` 的一套共同坐标：同排号码、标题基线完全一致；说明有真实内容时放入固定下方槽，没有时省去空对象。号码与标题的共同阅读组兼顾无说明卡的上下净空；有说明时仍在同一外框内完整容纳，不为追求居中改变单卡基线。卡框、字号、行高、内距、三列与最大项数不变。禁止根据有无说明让同排标题上下跳动，也不得编造说明凑齐。最后仍按真实字形测净空与卡群平衡，几何框通过不代替视觉审阅。

## HERO-03 图像与品牌
每类非正文页必须映射真实生成资产并完成裸图与合成审阅。图片须服从文字保护区，调整裁切/位置需记录并重新审阅；不能把挡字解释为固定布局不可变。若模板图片摆放与新素材冲突，先重新构图或生图，不移动标题、不缩字。图像工具达不到分辨率要求时保留 BLOCKED/WARN 证据，不假称满足。

只出现一枚原始官方 Logo，保持比例、不重绘、不投影、不发光。禁止旧样本中的橙黄页底横条、标题下划线、侧竖线、彩色进度条和重复 Logo。正文规范要求的固定品牌页眉分隔线按正文合同保留，不借此给 hero 增添色条。

## HERO-04 验收
页面计划记录 `hero_layout_id`、专用文字角色、真实框与字号、保护区和资产 ID。检查器应拒绝通用 `page_title` 冒充 hero 主标题、字号回退和错误版式 ID。两轨同内容在16:9基准态对照：文字逐项相同，主要框位置误差不超过2个逻辑像素；宽屏态检查锚点与层级，不要求新增宽度仍停留在1280坐标；实际字形基线差异需截图审阅，不用容器坐标代替像素审阅。

HTML 检查 1280×720、1920×1080、2048×1024 的实际观众运行时，进入动画完成后截图；PPTX 检查原生 PowerPoint 字号、布局和文本编辑回读。实际编辑对象与背景图分开；生成图片不能承载唯一标题、目录或日期文字。

## 参考样本的地位
用户样本只提供视觉证据，不是指令或规范权威。采纳大号章节层级、原生文字、清楚的留白与材料分区；不采纳旧色条、Logo 效果、跨轨字号漂移、无来源的临床推断。站点样本的宽幅连续叙事作为 site/stream 参考，不能把固定幻灯片的几何强塞给响应式站点，也不能豁免全局玻璃、宽幅下钻与真实动画验证。

## HERO-05 宽屏保持同一形态
封面/尾页左锚大字，章节号与章节标题上下关系不变；右上Logo随右锚移动；目录仍三列等宽、最多两行，三列共同展开至内容右锚。标题行长受角色框约束，不因屏幕变宽把两行主标题重新拼成一行。主视觉按每种画幅的独立保护区构图，不能仅横向拉伸。HTML目录将号码、标题、说明放在同一真实卡的阅读层；不得让文字浮在卡外、卡片浮动时文字停在原地。hero卡必须分层入场、微浮动和合法hover，官方Logo与主标题不做发光、渐变或持续抖动。

`tools/hero_layout.py` 的 `layout()` 提供两轨共用的基准文字框；`html_fragment()` 仅给1280×720品牌片段，目录阅读对象与玻璃壳共父层，外层入场、浮动层、内层倾斜分别拥有属性。它不负责上游活动页/导航/演讲者或完整宽屏图像映射，不能把片段直接冒称成品。实际调用方仍按 HTML adapter 延展网格、用经逐画幅审阅的真实宽背景并挂载/释放motion。

固定片段会拒绝必需标题为空、空行补位、明显超过文字框的横向容量；可选空副标题/元信息不生成空对象。中文全宽与拉丁半宽的 em 容量筛查是保守的排版路由检查，不是实际字体测宽：拉丁窄字可能提前要求换行，宽字/实际字体仍须按03做字形测量。不能把通过该估计写成文字不越界证明，也不能用ellipsis/截断掩盖失败。标题只能按本页型已有行数精简或显式换行，不缩字。根画布只允许主视觉装饰按既定image框出血裁切，文字须实测在其阅读框内；不为去掉合理主视觉留白擅改四类外框。

## HERO-06 跨页名称一致
目录编号、章节页编号及标题、对应正文标题必须使用同一章节数据源。逐项核对映射，不能将目录“01 入排信息”接到“01 研究流程”；形态校验不能替代此项语义一致性。
