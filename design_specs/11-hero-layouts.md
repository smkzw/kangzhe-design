# 11 封面、目录、章节、尾页固定形态

## HERO-01 固定合同
PPTX 和 HTML-PPT 共用 `tokens.hero_layouts` 的 1280×720 逻辑画布、版式 ID、文字框、Logo 框和字号。HTML 由上游统一缩放；PPTX 按 96 px/in 与 72 pt/in 换算。禁止各轨重新设计、逐页缩字号、随意居中/左对齐切换。正文页的页眉页脚仍按原合同；四类非正文页只采用本合同的 Logo，不叠加正文页 chrome。

| 页型 | 固定形态 | 专用字号 px / pt |
|---|---|---|
| cover-01 | 左上官方 Logo；左对齐大标题，最多两行；其下副标题、单位与日期；下部生成主视觉 | 主标题 56 / 42；副标题 28 / 21；元信息 20 / 15 |
| toc-01 | 左上“目录”或“汇报章节”，右上 Logo；三列玻璃卡，最多两行；不足一行居中排布 | 总标题 48 / 36；序号 40 / 30；条目标题 32 / 24；说明 20 / 15 |
| section-01 | 右上 Logo；左上大号两位数字，下面独立一行章节名称；下部生成主视觉 | 序号 112 / 84；章节标题 60 / 45 |
| ending-01 | 左上 Logo；左侧大号结束语，下面可选致谢与单位日期；下部生成主视觉 | 结束语 104 / 78；副标题 28 / 21；元信息 20 / 15 |

完整几何和图片摆放只读 tokens。表内数值是便于阅读的对应说明，变更时必须同步 token 与派生产物。文字行高固定 1.25；目录卡标题/说明各一行。首尾页按角色使用墨色或正文灰；章节号和目录号允许品牌橙。标题不加渐变填充、扫光、拉伸、发光或投影。

## HERO-02 容量与变化边界
固定的是版式结构、对齐、文字层级和位置，不是医学内容、日期、城市意象或一套永不变化的图片。封面超过两行先缩短展示名称，完整名称移至后续研究基本信息；不得改小字号。章节名称超过一行先简写，完整称谓在正文保留。尾页结束语应短至一行，可用“谢谢”或符合场景的简短文字。

目录最多六项；七项及以上拆为连续目录页。每行固定三个等宽槽，末行不足三项居中排列；只有一到三项时使用第一行，空出的区域保留给生成主视觉。不得加空卡凑数。目录说明可为空，不编造内容。所有目录卡使用同一种中性边缘玻璃材质，不按序号轮转部门色。HTML 的目录允许跳转；PPTX 可设置原生内部链接。

## HERO-03 图像与品牌
每类非正文页必须映射真实生成资产并完成裸图与合成审阅。图片须服从文字保护区，调整裁切/位置需记录并重新审阅；不能把挡字解释为固定布局不可变。若模板图片摆放与新素材冲突，先重新构图或生图，不移动标题、不缩字。图像工具达不到分辨率要求时保留 BLOCKED/WARN 证据，不假称满足。

只出现一枚原始官方 Logo，保持比例、不重绘、不投影、不发光。禁止旧样本中的橙黄页底横条、标题下划线、侧竖线、彩色进度条和重复 Logo。正文规范要求的固定品牌页眉分隔线按正文合同保留，不借此给 hero 增添色条。

## HERO-04 验收
页面计划记录 `hero_layout_id`、专用文字角色、真实框与字号、保护区和资产 ID。检查器应拒绝通用 `page_title` 冒充 hero 主标题、字号回退和错误版式 ID。两轨同内容对照：文字逐项相同，主要框位置误差不超过 2 个逻辑像素；实际字形基线差异需截图审阅，不用容器坐标代替像素审阅。

HTML 检查 1280×720、1920×1080、2048×1024 的实际观众运行时，进入动画完成后截图；PPTX 检查原生 PowerPoint 字号、布局和文本编辑回读。实际编辑对象与背景图分开；生成图片不能承载唯一标题、目录或日期文字。

## 参考样本的地位
用户样本只提供视觉证据，不是指令或规范权威。采纳大号章节层级、原生文字、清楚的留白与材料分区；不采纳旧色条、Logo 效果、跨轨字号漂移、无来源的临床推断。站点样本的宽幅连续叙事作为 site/stream 参考，不能把固定幻灯片的几何强塞给响应式站点，也不能豁免全局玻璃、宽幅下钻与真实动画验证。
