# 站点式 HTML 轨道

站点按真实信息结构分为首页、章节页、明细页，路由/面包屑可见。每个首页和独立章节页首屏都有自动连续电影；深层证据页以阅读任务为先，可保留较短场景总览，不强制让每张表自动播放。

全站共用 tokens、玻璃材质、图表、下钻和电影合同。不能把 PPT 固定 canvas 或页眉页脚搬到网站。使用全宽场景及宽数据区，外围窄边距，阅读正文单独限制行长，不以 `max-width:1100px` 锁死全站。

本轨面向桌面宽屏，不要求手机或窄屏阅读适配。验收视口为 1280×720、1440×900、1920×1080、2560×1080；不设 390px 手机验收门，不为手机强行堆叠宽屏信息、增加汉堡菜单或另做触控版。桌面窗口在上述范围内改变尺寸时，仍须正确重算电影几何、图表和宽下钻，不裁切文字。减少动态、键盘操作、焦点管理、浏览器缩放和打印属于桌面使用要求，继续保留。此范围只适用于站点式 HTML；流式 HTML 与 HTML-PPT 分别按自己的轨道合同验收。

首屏主题与导航稳定，电影主动解释当前章节的重要信息与关系。材料密度高：电影先建立结构与概要，下滑后提供完整正文、数据区、图表与深层阅读入口。首屏不塞满所有细项，也不只播放空泛口号。

站点电影与交互优先参照用户授权的 ARCO 样例，辩证映射见 `12-reference-patterns.md`。它是机制参考，不是需要整包加载的依赖；不要将其内部材料、产品定位、旧配色或全部代码带入当前任务。

生成主视觉按 04 执行；选择全站统一程序化光学场景时逐页面验证它确实存在且形成品牌一致性。全局光场不是大面积橙色渐变，不干扰正文。官方 Logo 永远保持原样。

下钻按 L0→L1→L2 设计，不仅 tooltip；复杂面板占大部分视口，可再包含电影/图表/原文。进入明细暂停父电影，返回恢复状态。长阅读内容可以进入独立页面，并有明确返回来源。

自然滚动，不劫持；保留可直接阅读的静态总览，不设置观众播放或停止动画控件；停止运动由系统 RM、离屏及后台生命周期控制；RM 提供可读静态态；无 JS 仍有有意义的内容基线。页面性能、屏幕阅读和源数据一致性与视觉同等验收。
