# HTML-PPT 轨道

必须从 `lewislulu/html-ppt-skill` 脚手架和模板进入；路径计算、唯一 deck 容器、缩放、活动页、键盘、hash、S 演讲者窗口、notes 由它拥有。本包提供主题 CSS 和功能桥接，不创建第二个 slideshow。

固定逻辑画布 1280×720，设置上游支持的 `data-w="1280" data-h="720"`；不使用 fluid opt-out。CSS 在 base/theme 之后加载且限定 `.kz-deck`。Logo 通过其声明接口只生成一次，hero 如需不同位置用上游 `data-no-logo` 并自带一个 logo；不得双重标识。

加载共享玻璃、图表、下钻/甘特和电影能力，按使用情况装配。活动页离开时停止该页动画、关闭其模态状态或保存状态后隐藏，不能留下 invisible 页面截获点击。普通模式正常运行，preview/print/静态检查使用稳定数据终态；电影规定总览在静态模式可见。

每个正文页保持同一页眉页脚及单行主题标题。四类非正文页全部有生成主视觉，文字和标签单独保护。正文背景共享生成资产时逐页登记；不能因正文有 ECharts 就连外缘的安静图像也一律禁止。

动画：每卡分组入场/退出、hover 光影、非数据面 ±10° tilt；流程顺序呈现；图表/甘特与数字共享进度；合适页面用连续电影。双菱形和 hero 卡可极小幅浮动。不允许用“严肃”作为完全没有动效的借口，也不让统计图被透视扭曲。

下钻打开宽面板，复杂信息可继续 L2。甘特编辑器保持至少 16px，图 3/4 + 编辑器 1/4 或上图下框。输入框/滑块/拖拽激活时屏蔽 **上游对应的翻页快捷键传播**，但不另写导航。不要全局禁用所有键盘操作。

与正式引擎的 glue 及上游已读源码边界见 adapters/html-ppt.md。参考组件页不是 HTML-PPT 完成实例。
