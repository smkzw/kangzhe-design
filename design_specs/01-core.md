# 01 品牌与正文页固定结构

## 色彩 CORE-01
主橙、辅黄、墨色、正文灰和四个部门色读取 `tokens.colors` 与 `tokens.departments`。浅色为共同基底；医学橙、运营蓝、数统绿、PV 棕只表达已知的部门身份，同一部门不跨轨换色，也不拿来当通用图表系列色或焦点色（图表见 05 CHART-03，焦点环用 `colors.focus`）。

- 状态不能只靠颜色，文字、形状或标记同时表达。
- 主橙不作小字号正文色；橙底按钮用深色文字。深红 `#C00000` 只按 03 COPY-04 使用。
- 视觉预算按可见视口估计：浅色占主导，高饱和橙黄只作有限识别与重点（`tokens.brand_budget`）。玻璃面的暖色反光不计入大面积橙色；也不能把整页降饱和成米黄色来“守预算”。

## 官方 Logo CORE-02
只用随包 `assets/logo_bot.svg`，校验 `tokens.logo.sha256`。不改字形、色彩、比例和名称，不重绘，不做玻璃化、透视、发光或描边。导出器需要位图时，从原 SVG 原样渲染透明 PNG（记录倍率），不手工重画。项目或概念标识另有委托时才允许生成玻璃化标识，不得生成近似官方 CMS 的图形替代正式素材。

## 画布与锚定 CORE-03
PPTX 为 1280×720。HTML-PPT 在 16:9 基准态保持同一几何；普通放映采用上游 `body[data-fit="fluid"]` 全视口主题（见 adapters/html-ppt.md）。品牌固定的是轮廓、上下位置、字号层级和左右锚定：左侧双菱形与标题不挪，右侧 Logo 与页码贴规定右边距，分隔线延展到右锚。不拉伸菱形、Logo 或文字。新增的宽度要被内容网格和背景实际使用，不能在居中的 16:9 片两边涂背景冒充适配。不叠加第二套缩放或翻页引擎。

## 正文页 chrome CORE-04（PPTX / HTML-PPT）
正文页固定为：左上双菱形（02 LG-03）、单行页标题、橙色横线、右上完整 Logo；内容只放在 `tokens.chrome.body` 区内。页脚恰好两槽：左侧“产品中心-医学部｜YYYY年M月”（`tokens.chrome.footer`），右侧物理页序 `N / TOTAL`，总页数含封面等页面。页脚不写来源、编制方或第三段说明。

HTML-PPT 的页码可以用上游 `.slide-number` 运行时机制，也可以在构建时写成每页静态文本；两种都必须真实显示数字，空槽即失败。需要打印的 deck 把 chrome 放在每张正文页内，因为上游打印样式会隐藏 deck 级页眉页脚。

封面、目录、章节、尾页不套正文页 chrome，不显示页码，各自只保留一个官方 Logo，固定形态见 11。站点式与流式 HTML 不使用双菱形和 PPT 页眉页脚，用正常站点导航（13 FOLD-02）。

## 图层 CORE-05
0 页面浅底；1 背景图或程序光场；2 局部遮罩与低频光学层；3 玻璃容器；4 图表/表格/正文；5 标签与交互控件；6 固定品牌 chrome。装饰层 `pointer-events:none`；高光和阴影不越层干扰。生成图不得烘焙页眉页脚、图表数据、标题或正文。

## 引用行 CORE-06
只有满足 03 COPY-05 的文献才在正文区预留独立参考行，不与主内容、页脚重叠；没有合格文献时整行消失。不保留“来源：内部资料”或文件名类占位。

## 不可编辑素材边界 CORE-07
官方 Logo、原始医学影像与已发表图、生成背景可以是图片；正文、卡片结构、普通统计图、时间条、表格和标注必须可编辑。原始证据图不由 AI 重绘；需要说明时用独立文本对象。图像原有的科学必要标签不删。
