演示动画的二十八种形式

同一份合成示例（研究资料完整性核对）用二十八种演示形式讲述。每块舞台都由数据驱动：图标、点、柱、数字、路径与说明都从数据算出，场景之间对象保持同一身份。前六种是 7.1.2 的基础形式，第 7–16 种是以示意图为主的高密度形式，包括流程正反例与甘特推进；第 17–21 种是同一任务下更轻的细颗粒形式（份数格、逐级漏斗、前后变化、里程碑、单例路径）。版式在左右分栏、右栏、整宽与堆叠之间轮换。站点中自动循环播放；放进 HTML-PPT 时按 scene 由演讲者翻页推进。

形式 1 · 单位流动

一个方块代表一份资料

  • 适合：计数、清点、入组与脱落、资料或样本的去向
  • 动作：散点归组 → 状态着色 → 缺口放大 → 缺失飞入补收清单
  • 依据：每个方块对应一条记录，数量从数据算出
形式 2 · 计算演示

数字从原表飞进算式

  • 适合：剂量换算、窗口期推算、样本量、合计与差额
  • 动作：原表 → 逐项相加 → 相减得结果 → 逐行核对回原表
  • 依据：算式与结果都由数据计算，终值即真值
形式 3 · 数据动画图

同一组数据逐幕换编码

  • 适合：结果解读、亚组差异、构成与总量
  • 动作：应收柱 → 叠已收 → 差额标红 → 按缺口重排 → 堆叠成总量
  • 依据：全程同一刻度；空值不当 0；颜色跟随实体
形式 4 · 时间轴推演

时间指针逐季走过计划

  • 适合：项目计划、访视日程、给药周期、里程碑
  • 动作：指针逐季推进，任务条随之延伸，完成打勾，里程碑季度展开
  • 依据：季度模型 [start, end)，每幕说明由任务数据生成
形式 5 · 判定走查

示例个案沿规则路径前进

  • 适合：入排判定、SAE 上报、偏离处理、资料核对规则
  • 动作：路径绘出 → 示例 A、B、C 依次走过各自分支 → 结果计数
  • 依据：路径来自材料中的规则；个案明确标为示例
形式 6 · 版本对比

两版逐条对齐，差异拉出

  • 适合：方案修订、说明书更新、两种做法对比
  • 动作：两版并排 → 滑到一起对齐 → 一致条目锁定 → 差异条目拉出转交
  • 依据：逐条比对两版取值，一致与差异由取值算出；只列材料中的条目
形式 7 · 流程正反例

一份资料走完核查流程

  • 适合：资料入库、SAE 上报、偏离处理、审批链
  • 动作：正例一次通过 → 简单反例退回返工 → 复杂反例反复不合格后升级 → 各环节问题计数
  • 依据：环节、规则与示例路径来自数据；返工与升级由每步结果算出
形式 8 · 甘特推进

延误怎样沿依赖传导

  • 适合：项目计划、核对计划、注册与上市节点
  • 动作：计划 → 当前进度 → 一项延误与顺延 → 关键路径 → 追赶方案
  • 依据：依赖关系逐项前推排期，里程碑与关键路径都由排期算出
形式 9 · 跨部门泳道

问题单在部门间流转

  • 适合：跨部门交接、上报时限、审批流转
  • 动作：问题单逐段穿过泳道，累计用时，超时环节标出
  • 依据：每段用时与时限来自数据，合计与超时由数据算出
形式 10 · 受试者流

从筛选到进入分析

  • 适合：入组流程、受试者处置、样本去向
  • 动作：筛选 → 排除并列明原因 → 随机分组 → 脱落 → 进入分析
  • 依据：一个点代表固定人数；各组合计与随机化人数不符时直接报错
形式 11 · 曲线解读

逐段读一张趋势图

  • 适合：疗效随时间变化、完成率、实验室指标
  • 动作：画出第一组 → 同刻度画对照 → 目标线 → 窗口差值 → 事件标注
  • 依据：空值不连线；差值与达标时点数由数据算出
形式 12 · 总量拆解

从总量到问题所在

  • 适合：构成分析、缺口来源、预算与资源分布
  • 动作：总量 → 分块 → 聚焦一块 → 展开子项 → 放回总量
  • 依据：面积按数值，占比由数据算出；子项合计须等于母项
形式 13 · 文档核查

逐项核一张核查表

  • 适合：源文件核查、资料完整性、规范符合性
  • 动作：放大镜逐段核对 → 不符项飞入发现清单 → 相符率
  • 依据：字段、取值与规则来自数据；不改写原值
形式 14 · 风险矩阵

措施前后的风险落位

  • 适合：风险评估、问题分级、优先级排序
  • 动作：风险落位 → 高风险区计数 → 措施后移位 → 前后对比
  • 依据：评分 = 可能性 × 影响；高风险阈值写在数据里
形式 15 · 数据流

一份数据卡在哪条通道

  • 适合：数据流转、系统接口、样本与文件传递
  • 动作：各方与通道 → 数据逐份送达 → 一份在中断通道受阻 → 汇总
  • 依据：路径与阻断位置来自数据；阻断须在该数据的路径上
形式 16 · 访视窗口

实际访视对照允许窗口

  • 适合：访视计划、给药周期、随访依从性
  • 动作：画出各次访视的窗口 → 逐个受试者落点 → 超窗与缺访标出 → 汇总
  • 依据：窗口与实际日期来自数据，偏离天数由数据算出
形式 17 · 逐格到位

一行一组，一格一份

  • 适合：资料、样本、访视的到位与完成度（细颗粒，可与 units 换用）
  • 动作：空格铺开 → 已收填色 → 缺口描红 → 排成一条看整体占比
  • 依据：格数即应收，填色数即已收，占比由数据算出
形式 18 · 逐级流失

每一级流失移到台账

  • 适合：筛选到完成、转化与流失、逐级审批通过率
  • 动作：等宽起步 → 逐级收窄 → 各级流失移到右侧台账 → 最大流失标红
  • 依据：逐级不增，流失与占比由相邻两级算出
形式 19 · 前后变化

灰条留住过去，橙条是现在

  • 适合：两个时点的指标对比、措施前后
  • 动作：前值 → 变到后值（灰条留位）→ 升降按好坏着色 → 改善与变差分拣
  • 依据：每项各自刻度；好坏由 good 方向判定
形式 20 · 里程碑推进

指针走到当前，点名下一站

  • 适合：计划节点、注册与上市里程碑、项目阶段
  • 动作：轨道 → 节点落下 → 指针走到当前、已过节点变色 → 下一节点点亮
  • 依据：now 是走到第几项（可为小数），已过与下一节点由它算出
形式 21 · 路径走查

一份示例资料走完步骤

  • 适合：线性流程、操作步骤、单条路径的核对（分支多时用 decision / flow）
  • 动作：步骤与路径 → 示例沿路径前进 → 在标记步骤停下 → 退回或归档
  • 依据：步骤与标记来自数据；示例明确标注
形式 22 · 安全性总览

不良事件逐类比较

  • 适合：TEAE、TRAE、≥3 级、TESAE、TRSAE、AESI、停药、死亡等安全性总览（场景族：安全性汇总）
  • 动作：分析集 N → 任何 TEAE → TEAE 拆成各下级类别（子条从上级条里分出）→ 其余类别 → 差值移入台账、超阈值标红 → 重点类别
  • 依据：百分比与差值由例数和 N 算出；与静态模板 safety-overview、旗舰舞台 safety 共用一份数据
形式 23 · 临床开发计划

多适应症开发进度

  • 适合：多适应症临床开发计划（关键性里程碑）、单适应症各研究的细化节点（首例入组、末例入组、锁库、顶线）（场景族：开发计划）
  • 动作：泳道与季度轴 → 各阶段按时间铺开 → 当前线走到当前季度、之后的部分转为计划 → 里程碑钉到阶段条上（已过实心、未来空心）→ 重点泳道与里程碑
  • 依据：季度写成 2026Q3，内部与可编辑甘特同一 [起, 止) 模型；与静态模板 program-plan、旗舰舞台 program 共用一份数据
形式 24 · 暴露例数汇总

各适应症按暴露时长累计

  • 适合：多适应症暴露例数汇总、长期暴露是否达到 ICH E1 等目标（场景族：暴露例数汇总）
  • 动作：各组空轨 → 任何暴露全部生长 → 更长的时长档由浅到深依次填入（长档是短档的子集）→ 合计对照目标（达到为绿、未达为红）→ 重点组
  • 依据：合计、占比与目标差额由每组例数算出；与静态模板 exposure-summary、旗舰舞台 exposure、旗舰 PPTX flag-exposure 共用一份数据
形式 25 · 试验流程

从筛选到随访的分组与再随机化

  • 适合：研究设计流程，含共同阶段、随机化、剂量递增与维持、再随机化子流程、共同随访与子研究（场景族：试验流程）
  • 动作：共同阶段 → 随机化节点分出各组 → 各组段落沿周轴铺开 → 再随机化分出子分组 → 终点与共同随访 → 子研究 → 重点组
  • 依据：时间轴分段线性（短的筛选期不被压扁），比例与例数取自数据；与静态模板 trial-flow、旗舰舞台 trialflow、旗舰 PPTX flag-trialflow 共用一份数据
形式 26 · 竞争格局

本品与竞品的阶段、疗效与安全性

  • 适合：竞品格局，研发进度、一个有效性与一个安全性指标同表比较（场景族：竞争格局）
  • 动作：按研发阶段排开 → 阶段色块轨填到当前阶段 → 疗效条长出并按疗效重排 → 安全性条长出 → 重点（默认本品）
  • 依据：排序、名次与最佳值由数据算出，无数据写“—”不当 0；竞品为合成示例；与静态模板 landscape、旗舰舞台 landscape、旗舰 PPTX flag-landscape 共用一份数据
形式 27 · 有效性汇总

主要与次要终点逐行对照

  • 适合：主要、关键次要与次要终点的各组结果，连续变量与二分类同页（场景族：有效性汇总）
  • 动作：终点与各组数值 → 连续变量一段的差值与 95% CI 逐个画出 → 二分类一段 → CI 跨 0 的终点单独点出 → 重点终点
  • 依据：每段一条含 0 的差值轴，CI 不跨 0 且方向有利为实心、跨 0 为空心、方向不利为红；率差与 n/N 一致才放行；与静态模板 efficacy-summary、旗舰舞台 efficacy、旗舰 PPTX flag-efficacy 共用一份数据
形式 28 · 访视流程 SoA

每次访视做哪些评估

  • 适合：研究访视安排的概览，按分组看评估集中在哪些访视、哪次访视负担最重（场景族：SoA）
  • 动作：访视列与分期 → 各分组逐个落点（点的大小 = 该访视的项目数）→ 每次访视评估数长出、最忙的访视点亮 → 重点项目的访视
  • 依据：计数、最忙访视与分期跨度由数据算出，分期不连续或项目全无标记直接报错；逐项明细用静态模板 soa（按访视分页）；与旗舰舞台 soa、旗舰 PPTX flag-soa 共用一份数据
自定义

没有合适形式时，直接写 scene

  { id: 'b', caption: '缺口移到右侧', set: { box: { x: .7, fill: '#C00000', via: [[.4, .1]] } } },
] });
