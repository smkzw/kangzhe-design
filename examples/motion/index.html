演示动画的十六种形式

同一份合成示例（研究资料完整性核对）用十六种演示形式讲述。每块舞台都由数据驱动：图标、点、柱、数字、路径与说明都从数据算出，场景之间对象保持同一身份。前六种是 7.1.2 的基础形式，后十种是以示意图为主的高密度形式，包括流程正反例与甘特推进。版式在左右分栏、右栏、整宽与堆叠之间轮换。站点中自动循环播放；放进 HTML-PPT 时按 scene 由演讲者翻页推进。

形式 1 · 单位流动

一个方块代表一份资料

  • 适合：计数、清点、入组与脱落、资料或样本的去向
  • 动作：散点归组 → 状态着色 → 缺口放大 → 缺失飞入补收清单
  • 依据：每个方块对应一条记录，数量从数据算出
形式 2 · 计算演示

数字从原表飞进算式

  • 适合：剂量换算、窗口期推算、样本量、合计与差额
  • 动作：原表 → 逐项相加 → 相减得结果 → 逐行核对回原表
  • 依据：算式与结果都由数据计算，终值即真值
形式 3 · 数据动画图

同一组数据逐幕换编码

  • 适合：结果解读、亚组差异、构成与总量
  • 动作：应收柱 → 叠已收 → 差额标红 → 按缺口重排 → 堆叠成总量
  • 依据：全程同一刻度；空值不当 0；颜色跟随实体
形式 4 · 时间轴推演

时间指针逐季走过计划

  • 适合：项目计划、访视日程、给药周期、里程碑
  • 动作：指针逐季推进，任务条随之延伸，完成打勾，里程碑季度展开
  • 依据：季度模型 [start, end)，每幕说明由任务数据生成
形式 5 · 判定走查

示例个案沿规则路径前进

  • 适合：入排判定、SAE 上报、偏离处理、资料核对规则
  • 动作：路径绘出 → 示例 A、B、C 依次走过各自分支 → 结果计数
  • 依据：路径来自材料中的规则；个案明确标为示例
形式 6 · 版本对比

两版逐条对齐，差异拉出

  • 适合：方案修订、说明书更新、两种做法对比
  • 动作：两版并排 → 滑到一起对齐 → 一致条目锁定 → 差异条目拉出转交
  • 依据：逐条比对两版取值，一致与差异由取值算出；只列材料中的条目
形式 7 · 流程正反例

一份资料走完核查流程

  • 适合：资料入库、SAE 上报、偏离处理、审批链
  • 动作：正例一次通过 → 简单反例退回返工 → 复杂反例反复不合格后升级 → 各环节问题计数
  • 依据：环节、规则与示例路径来自数据；返工与升级由每步结果算出
形式 8 · 甘特推进

延误怎样沿依赖传导

  • 适合：项目计划、核对计划、注册与上市节点
  • 动作：计划 → 当前进度 → 一项延误与顺延 → 关键路径 → 追赶方案
  • 依据：依赖关系逐项前推排期，里程碑与关键路径都由排期算出
形式 9 · 跨部门泳道

问题单在部门间流转

  • 适合：跨部门交接、上报时限、审批流转
  • 动作：问题单逐段穿过泳道，累计用时，超时环节标出
  • 依据：每段用时与时限来自数据，合计与超时由数据算出
形式 10 · 受试者流

从筛选到进入分析

  • 适合：入组流程、受试者处置、样本去向
  • 动作：筛选 → 排除并列明原因 → 随机分组 → 脱落 → 进入分析
  • 依据：一个点代表固定人数；各组合计与随机化人数不符时直接报错
形式 11 · 曲线解读

逐段读一张趋势图

  • 适合：疗效随时间变化、完成率、实验室指标
  • 动作：画出第一组 → 同刻度画对照 → 目标线 → 窗口差值 → 事件标注
  • 依据：空值不连线；差值与达标时点数由数据算出
形式 12 · 总量拆解

从总量到问题所在

  • 适合：构成分析、缺口来源、预算与资源分布
  • 动作：总量 → 分块 → 聚焦一块 → 展开子项 → 放回总量
  • 依据：面积按数值，占比由数据算出；子项合计须等于母项
形式 13 · 文档核查

逐项核一张核查表

  • 适合：源文件核查、资料完整性、规范符合性
  • 动作：放大镜逐段核对 → 不符项飞入发现清单 → 相符率
  • 依据：字段、取值与规则来自数据；不改写原值
形式 14 · 风险矩阵

措施前后的风险落位

  • 适合：风险评估、问题分级、优先级排序
  • 动作：风险落位 → 高风险区计数 → 措施后移位 → 前后对比
  • 依据：评分 = 可能性 × 影响；高风险阈值写在数据里
形式 15 · 数据流

一份数据卡在哪条通道

  • 适合：数据流转、系统接口、样本与文件传递
  • 动作：各方与通道 → 数据逐份送达 → 一份在中断通道受阻 → 汇总
  • 依据：路径与阻断位置来自数据；阻断须在该数据的路径上
形式 16 · 访视窗口

实际访视对照允许窗口

  • 适合：访视计划、给药周期、随访依从性
  • 动作：画出各次访视的窗口 → 逐个受试者落点 → 超窗与缺访标出 → 汇总
  • 依据：窗口与实际日期来自数据，偏离天数由数据算出
自定义

没有合适形式时，直接写 scene

舞台里放带 data-kz-obj 的对象，scene 只写变化；没写的属性沿用上一幕。几何取画布比例（0–1）。

const stage = KZScenes.mount(root, { loop: true, scenes: [
  { id: 'a', caption: '应收 24 份', set: { box: { x: .1, y: .3, w: .2, h: .3, fill: '#D5DBE1' } } },
  { id: 'b', caption: '缺口移到右侧', set: { box: { x: .7, fill: '#C00000', via: [[.4, .1]] } } },
] });
