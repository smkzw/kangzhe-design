# 参考组件与能力边界

公开构造/挂载/生命周期签名见 [API.md](API.md)。先按页型选择接口，必要时只展开相应实现定义，不以能力表猜方法。

所有文件使用 `.kz` 作用域和 `window.KZ*` 名称。不是新的 PPT 引擎。加载顺序见 `examples/component-lab.html`。

| 文件 | 已实现的参考范围 | 未覆盖的生产范围 |
|---|---|---|
| kz-motion.js | 同 DOM 载体几何/材料连续变形、seek、暂停原因集合、可见性/减少动态、入退出、±10° tilt | 任意 SVG path 拓扑、复杂领域电影编排、多载体关系图、GPU 真实折射 |
| kz-charts.js | ECharts 折线浅面积/柱/条、固定轴动画、数字回调、null 缺口、legend 状态保留 | 生存/森林/置信区间/复杂组合图专用转换；不得用基础图代替 |
| kz-gantt.js | 季度移动/两端拖伸/表单/键盘/撤销/还原、序列化回读、编辑前结束入场动画 | 月/日单位、依赖自动级联、多人持久化、任意任务结构导入 |
| kz-drilldown.js | 同一宽对话框的多层栈、图表/电影生命周期、滚动/焦点恢复 | 应用路由历史、权限、服务端数据持久化 |
| html-ppt-bridge.js | 上游已有 active 状态的组件生命周期桥 | 不是上游端到端集成或新的导航器 |

`Film` 是连续形变底座，不能仅换标签就把它当成复杂科学机制的合格动画电影。项目必须按电影规范补充实体关系、数据联动、阶段说明和完整静态详情。浏览器 reference 的存在不替代整页和上游工具验证。

组件默认不联网。任何数据持久化/上传或外部模型调用都不属于这些组件。示例的编程 API 便于自动测试，不强制添加导出文件按钮。

Film 的小视口适配保留主载体最小160px宽（舞台不足时最多88%舞台宽），重新约束横坐标；不把内部文字等比缩成小字。页面仍须检查实际扫掠区，而非只检查原始关键帧。复杂正文不放在最小状态载体内。

A04：Film本体不再查询、更新或绑定任何播放控件；pause/resume/seek仅为后台生命周期/QC接口。旧页面兼容清理仍由kz-audience承担，CSS只保留隐藏防线，不保留播放器布局样式。
