# 参考组件与能力边界

接口见 [API.md](API.md)。这些是可复用组件，不是新的 PPT 引擎；默认不联网，不做数据持久化或外部模型调用。

| 文件 | 已实现 | 未覆盖 |
|---|---|---|
| kz-tokens.css / .js | 由 `tools/build_tokens.py` 从 tokens 生成；含指针光与动态阴影配方 | — |
| kz-glass.css | 玻璃材质、阴影层级、Bento 首屏、KPI、状态条、电影结构、下钻、甘特外观、跨文档转场、减少动态与打印 | 主题之外的业务布局 |
| kz-motion.js | 分层编排入场、弹簧倾斜与光源、段落入场、光场视差、KPI 计数、分镜生成、关系连线、同节点载体形变、文字交叉淡入、暂停原因集合、seek、减少动态 | 任意 SVG 拓扑形变、复杂领域电影编排、GPU 折射 |
| kz-charts.js | ECharts 折线（左→右描出、浅面积、null 缺口）、柱/条（错峰长出）、固定轴、数字回调、固定类别色序 | 森林图、CI、KM、热图等专用图 |
| kz-gantt.js | 季度拖动/两端延展/表单/键盘/撤销/还原、序列化、错峰延伸 | 日粒度、依赖级联、多人协同、未知端点渲染 |
| kz-drilldown.js | 宽对话框层级栈、卡片展开与收回、焦点圈禁、按键与滚轮隔离、背景隔离 | 应用路由历史、权限、服务端数据 |
| kz-layout-qc.js | 卡内分布、阅读区越界、首屏覆盖率与空白、孤字行 | 审美与语义判断 |
| kz-audience.js | 清理旧产物残留的播放器控件（兼容层） | 新页面应从源头不生成这些控件 |

Film 是连续形变底座；只换标签不能算合格的电影（06 FILM-01）。载体最小宽度 `motion.film.min_carrier_width_px`，舞台不足时最多占舞台 88%，保护区检查用 `snapshot().geometry`。
